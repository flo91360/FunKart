# Polices du jeu

Polices libres (licence SIL Open Font License 1.1, texte complet dans les
fichiers `OFL-*.txt`), livrées avec le jeu pour qu'il ait la même allure sur
tous les ordinateurs :

- **Fredoka** (The Fredoka Project Authors) : textes et boutons de l'interface ;
- **Lilita One** (Juan Montoreano) : titres, logo, chiffres de la course ;
- **Andika** (SIL International) : le mot à taper, avec des lettres dessinées
  pour les enfants qui apprennent à lire.
